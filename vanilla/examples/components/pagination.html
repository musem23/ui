    Pagination

    Navigation for paginated content with page numbers, previous/next links, and ellipsis.

    Installation

    <link rel="stylesheet" href="css/components/pagination.css">

    Basic Pagination

    • Previous
    • 1
    • 2

    <nav class="pagination" role="navigation" aria-label="pagination">
  <ul class="pagination-content">
    <li class="pagination-item">
      <a href="#" class="pagination-link pagination-previous" aria-label="Go to previous page">
        <svg>...</svg>
        <span class="pagination-label">Previous</span>
      </a>
    </li>
    <li class="pagination-item">
      <a href="#" class="pagination-link">1</a>

    <li class="pagination-item">

    Active States

    Use aria-current="page", data-active="true", or .active class.

    • 1
    • 2
    • 3
    • 4
    • 5 
    <!-- Using .active class -->
<a href="#" class="pagination-link active">3</a>

<!-- Using aria-current (recommended for accessibility) -->
<a href="#" class="pagination-link" aria-current="page">3</a>

<!-- Using data attribute -->
<a href="#" class="pagination-link" data-active="true">3</a>

    CSS Classes Reference

    Class Description
    .paginationBase container for pagination navigation
    .pagination-contentList container for pagination items (flex row with gap)
    .pagination-itemList item wrapper (uses display: contents)
    .pagination-linkBase link/button style (36x36px square)
    .pagination-previousPrevious navigation button (wider with text label)
    .pagination-nextNext navigation button (wider with text label)
    .pagination-labelText label for prev/next (hidden on mobile)
    .pagination-ellipsisEllipsis indicator for page range gaps
    .activeActive/current page state (outline style)
    aria-disabled="true"Disabled state for navigation links
