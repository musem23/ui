    Alert Dialog

    A modal dialog that interrupts the user with important content and expects a response. Unlike regular dialogs, alert dialogs cannot be dismissed by clicking outside.

    Basic Example

    A standard confirmation dialog with cancel and confirm actions.

    Are you absolutely sure?

    This action cannot be undone. This will permanently delete your account and remove your data from our servers.

    Destructive Action

    Use a destructive variant for dangerous or irreversible actions.

    Delete Account

    Are you sure you want to delete your account? All of your data will be permanently removed. This action cannot be undone.

    Programmatic Control

    Open and close the dialog programmatically using JavaScript.

    Programmatic Dialog

    This dialog was opened using JavaScript. You can also close it programmatically. 

    // Get dialog instance
const dialog = BrandUI.AlertDialog(document.getElementById('my-dialog'));

// Open the dialog
dialog.open();

// Close the dialog
dialog.close('confirm');

// Listen for events
element.addEventListener('alert-dialog:action', (e) => {
  console.log('Action:', e.detail.action);
});
