    Programmatic Control

    Control the collapsible state via JavaScript API.

    This collapsible can be controlled programmatically using the JavaScript API.
    State: closed 
    // Get collapsible instance
const collapsible = BrandUI.getInstance(element, 'collapsible');

// Open
collapsible.open();

// Close
collapsible.close();

// Toggle
collapsible.toggle();

// Check state
const isOpen = collapsible.isOpen();

    Events

    Listen for collapsible state changes.

    Toggle this collapsible to see events fired in the output below.
    Events will appear here... 
    // Listen for state changes
element.addEventListener('collapsible:change', (e) => {
  console.log('Open:', e.detail.open);
});

// Listen for open event
element.addEventListener('collapsible:open', () => {
  console.log('Collapsible opened');
});

// Listen for close event
element.addEventListener('collapsible:close', () => {
  console.log('Collapsible closed');
});
