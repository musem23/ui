    Textarea

    A multi-line text input component for longer form content.

    Installation

    <link rel="stylesheet" href="css/components/textarea.css">

    Default

    <textarea class="textarea" placeholder="Type your message here..."></textarea>
    /* Required CSS */
@import "css/tokens.css";
@import "css/components/textarea.css";

/* Base class: .textarea */

    With Placeholder

    <textarea class="textarea" placeholder="Enter your feedback here..."></textarea>
<textarea class="textarea" placeholder="Write a detailed description..."></textarea>
    .textarea::placeholder {
  color: var(--muted-foreground);
}

    Disabled State

    <textarea class="textarea" disabled placeholder="This textarea is disabled"></textarea>
<textarea class="textarea" disabled>This content cannot be edited.</textarea>
    .textarea:disabled {
  cursor: not-allowed;
  opacity: 0.5;
}

    Invalid State

    <textarea class="textarea" aria-invalid="true">Too short</textarea>
    .textarea[aria-invalid="true"] {
  border-color: var(--destructive);
  box-shadow: var(--shadow-xs), 0 0 0 3px oklch(from var(--destructive) l c h / 20%);
}

    With Default Value

    <textarea class="textarea">Your pre-filled content here...</textarea>

    Custom Height

    <textarea class="textarea" style="min-height: 8rem;" placeholder="Taller textarea"></textarea>
<textarea class="textarea" style="min-height: 12rem;" placeholder="Even taller"></textarea>

    Read-only State

    <textarea class="textarea" readonly>Read-only content...</textarea>

    CSS Classes Reference

    Class / Attribute Description
    .textareaBase textarea class (required)
    placeholderHTML attribute for placeholder text
    disabledHTML attribute for disabled state (opacity 0.5, cursor not-allowed)
    aria-invalid="true"Attribute for invalid/error state styling
    readonlyHTML attribute for read-only state
