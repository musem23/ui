    Empty

    A placeholder component for empty states with optional icon, title, description, and actions.

    Installation

    <link rel="stylesheet" href="css/components/empty.css">

    Basic Empty State

    No messages
    You don't have any messages yet. Start a conversation to see your messages here.
    <div class="empty">
  <div class="empty-header">
    <div class="empty-icon">
      <svg ...>...</svg>
    </div>
    <div class="empty-title">No messages</div>
    <div class="empty-description">You don't have any messages yet.</div>
  </div>
  <div class="empty-actions">
    <button class="btn btn-default">New Message</button>
  </div>
</div>

    CSS Classes Reference

    Class Description
    .emptyContainer for empty state
    .empty-headerGroups icon, title, and description
    .empty-iconIcon container
    .empty-icon[data-variant="icon"]Smaller icon variant with background
    .empty-titleMain heading text
    .empty-descriptionSupporting description text
    .empty-contentAdditional content area
    .empty-actionsAction buttons container
