    Kbd

    A keyboard key indicator component for displaying keyboard shortcuts.

    Installation

    <link rel="stylesheet" href="css/components/kbd.css">

    Basic Usage

    K Esc Tab Enter 
    <kbd class="kbd">K</kbd>
<kbd class="kbd">Esc</kbd>
<kbd class="kbd">Tab</kbd>
<kbd class="kbd">Enter</kbd>
    /* Required CSS */
@import "css/tokens.css";
@import "css/components/kbd.css";

    CSS Classes Reference

    Class Description
    .kbdBase keyboard key class (required)
    .kbd-groupContainer for combining multiple keys
    .kbd > svgSVG icons are auto-sized to 0.75rem
    [data-slot="tooltip-content"] .kbdSpecial styling when used inside tooltips
