    Radio Group

    A set of checkable buttons where only one can be checked at a time.

    Basic

    A simple radio group with vertical orientation.

    <div class="radio-group" role="radiogroup" data-radio-group>
  <div class="radio-group-wrapper">
    <button id="opt1" class="radio-group-item" role="radio" aria-checked="true" data-value="opt1">
      <span class="radio-group-indicator"></span>
    </button>
    <label for="opt1">Option 1</label>
  </div>
  <!-- More options... -->
</div>

    Horizontal Orientation

    Radio group arranged horizontally.

    <div class="radio-group" data-radio-group data-orientation="horizontal">
  <!-- Radio items... -->
</div>

    Programmatic Control

    Control radio group state via JavaScript API.

    Selected: none
    // Get radio group instance
const group = BrandUI.getInstance(element, 'radio-group');

// Get current value
const value = group.getValue();

// Set value programmatically
group.setValue('option2');

// Listen for changes
element.addEventListener('radio-group:change', (e) => {
  console.log('Selected:', e.detail.value);
});

    Keyboard Navigation

    Radio groups support full keyboard navigation.

    • Arrow Up/Down (vertical) or Arrow Left/Right (horizontal): Move and select
    • Home: Move to first option
    • End: Move to last option
    • Space/Enter: Select current option
    • Tab: Move focus to/from the group
