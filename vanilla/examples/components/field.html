Components
    Field

    Field

    A form field wrapper that groups label, input, description, and error messages together.

    Installation

    <link rel="stylesheet" href="css/components/field.css">

    Basic Field

    A simple field with a label and input.

    <div class="field">
  <label class="field-label" for="email">Email</label>
  <input type="email" id="email" class="demo-input" placeholder="Enter your email">
</div>

    With Description

    Field with helpful description text below the input.

    This will be your public display name. You can change it later.

    <div class="field">
  <label class="field-label" for="username">Username</label>
  <div class="field-content">
    <input type="text" id="username" class="demo-input">
    <p class="field-description">This will be your public display name.</p>
  </div>
</div>

    Required Field

    Field with a required indicator on the label.

    <div class="field">
  <label class="field-label" data-required="true" for="name">Full Name</label>
  <input type="text" id="name" class="demo-input" required>
</div>

    Optional Field

    Field with an optional indicator.

    <div class="field">
  <label class="field-label" for="phone">
    Phone Number
    <span class="field-optional">(optional)</span>
  </label>
  <input type="tel" id="phone" class="demo-input">
</div>

    Error State

    Field with validation error message.

    Please enter a valid email address. 

    <div class="field" data-invalid="true">
  <label class="field-label" for="email">Email</label>
  <div class="field-content">
    <input type="email" id="email" class="demo-input" aria-invalid="true">
    <p class="field-error" role="alert">
      Please enter a valid email address.
    </p>
  </div>
</div>

    Multiple Errors

    Field with multiple validation errors displayed as a list.

    • Password must be at least 8 characters
    • Password must contain at least one number
    • Password must contain at least one special character

    Disabled State

    Field in a disabled state.

    This field cannot be modified.

    Horizontal Layout

    Field with label and input side by side.

    We'll never share your email.

    <div class="field" data-orientation="horizontal">
  <label class="field-label" for="email">Email</label>
  <div class="field-content">
    <input type="email" id="email" class="demo-input">
    <p class="field-description">We'll never share your email.</p>
  </div>
</div>

    Field Group

    Multiple fields grouped together.

    We'll send a confirmation to this email.

    <div class="field-group">
  <div class="field">...</div>
  <div class="field">...</div>
  <div class="field">...</div>
</div>

    Field Set

    Native fieldset with legend for grouping related fields.

    Contact Information 
    <fieldset class="field-set">
  <legend class="field-legend">Contact Information</legend>
  <div class="field-group">
    <div class="field">...</div>
    <div class="field">...</div>
  </div>
</fieldset>

    Field Separator

    Visual separator between field groups.

    or

</div>
