    Toast

    Notification toasts with stacking, types, positions, and auto-dismiss.

    Basic Usage

    Simple toast notifications with title and description.

    BrandUI.toast.show({
  title: 'Event Created',
  description: 'Your event has been scheduled.'
});

    Toast Types

    Different types for success, error, warning, and info states.

    // Using convenience methods
BrandUI.toast.success('Success', 'Operation completed.');
BrandUI.toast.error('Error', 'Something went wrong.');
BrandUI.toast.warning('Warning', 'Please review your input.');
BrandUI.toast.info('Info', 'New features available.');

    Positions

    Toast can appear in different positions on the screen.

    BrandUI.toast.show({
  title: 'Position Demo',
  position: 'top-center'
});

    Duration & Progress Bar

    Configure auto-dismiss duration and show progress bar.

    BrandUI.toast.show({
  title: 'Processing...',
  duration: 10000,
  showProgress: true
});

    Action Button

    Toast with an action button for user interaction.

    BrandUI.toast.show({
  title: 'Message sent',
  description: 'Your message was delivered.',
  action: {
    label: 'Undo',
    onClick: () => console.log('Undo clicked')
  }
});

    Promise API

    Automatically update toast based on promise resolution.

    const promise = saveData();

BrandUI.toast.promise(promise, {
  loading: { title: 'Saving...', description: 'Please wait.' },
  success: { title: 'Saved!', description: 'Data saved successfully.' },
  error: { title: 'Error', description: 'Could not save data.' }
});

    Stacking & Max Toasts

    Multiple toasts stack automatically. Oldest toasts are dismissed when limit is reached.

    // Configure max toasts globally
BrandUI.toast.configure({ maxToasts: 3 });

// Or dismiss all
BrandUI.toast.dismissAll();

    Global Configuration

    Configure default options for all toasts.

    BrandUI.toast.configure({
  duration: 5000,
  position: 'bottom-right',
  maxToasts: 5,
  closable: true,
  showProgress: false
});
