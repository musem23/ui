    Card

    A container component for displaying content and actions.

    Installation

    <link rel="stylesheet" href="css/components/card.css">

    Default

    Card Title
    Card description goes here.

    Card content with some text.

    <div class="card">
  <div class="card-header">
    <div class="card-title">Card Title</div>
    <div class="card-description">Card description goes here.</div>
  </div>
  <div class="card-content">
    <p>Card content with some text.</p>
  </div>
</div>
    /* Required CSS */
@import "css/tokens.css";
@import "css/components/card.css";

/* Card uses CSS variables from tokens.css */

    With Action

    Notifications
    You have 3 unread messages.

    View and manage your notification preferences.

    <div class="card">
  <div class="card-header">
    <div class="card-title">Notifications</div>
    <div class="card-description">You have 3 unread messages.</div>
    <div class="card-action">
      <button class="btn btn-secondary btn-sm">Mark all read</button>
    </div>
  </div>
  <div class="card-content">
    <p>View and manage your notification preferences.</p>
  </div>
</div>
    /* When card-header has a card-action child, it uses grid layout */
.card-header:has(.card-action) {
  grid-template-columns: 1fr auto;
}

.card-action {
  grid-column-start: 2;
  grid-row: 1 / span 2;
  align-self: start;
  justify-self: end;
}

  border-top: 1px solid var(--border);
}

    CSS Classes Reference

    Class Description
    .cardBase card container with background, border, and shadow
    .card-headerHeader section with grid layout for title/description
    .card-titleBold title text within header
    .card-descriptionMuted description text within header
    .card-actionAction button container (positions to right of header)
    .card-contentMain content area with horizontal padding
    .card-footerFooter section with flex layout
    .border-bAdd bottom border to card-header
    .border-tAdd top border to card-footer
