    Dialog

    A modal dialog component that overlays the page with focus trap, scroll lock, and keyboard support.

    Installation

    <link rel="stylesheet" href="css/components/dialog.css"> <script src="js/core.js"></script> <script src="js/components/dialog.js"></script>

    Controlled Close

    Important Notice

    This dialog requires you to make a choice. Clicking the overlay will not close it.

    <!-- Add data-close-on-overlay="false" to disable overlay close -->
<div id="controlled-dialog" data-dialog data-close-on-overlay="false">
  <div class="dialog-overlay"></div>
  <div class="dialog-content">
    <!-- No close button - user must click a button -->
    <div class="dialog-header">
      <h2 class="dialog-title">Important Notice</h2>
      <p class="dialog-description">...</p>
    </div>
    <div class="dialog-footer">
      <button data-dialog-close>I Understand</button>
      <button data-dialog-close>Continue</button>
    </div>
  </div>
</div>
    /* Disable ESC key as well */
<div data-dialog
     data-close-on-overlay="false"
     data-close-on-escape="false">
  ...
</div>

    Programmatic Control

    Programmatic Dialog

    This dialog was opened using JavaScript API.

    // Get dialog instance
const el = document.getElementById('my-dialog');
const dialog = BrandUI.getInstance(el, 'dialog');

// Open dialog
dialog.open();

// Close dialog
dialog.close();

// Toggle open/close
dialog.toggle();

// Destroy and cleanup
dialog.destroy();

    Events Demo

    Check the event log when opening and closing.

    const dialogEl = document.getElementById('my-dialog');

// Listen for open event
dialogEl.addEventListener('dialog:open', (e) => {
  console.log('Dialog opened', e.detail.dialog);
});

// Listen for close event
dialogEl.addEventListener('dialog:close', (e) => {
  console.log('Dialog closed', e.detail.dialog);
});

    CSS Classes Reference

    Class Description
    .dialog-overlaySemi-transparent backdrop
    .dialog-contentCentered modal container
    .dialog-headerHeader section (title + description)
    .dialog-titleDialog heading text
    .dialog-descriptionSupporting description text
    .dialog-footerFooter with action buttons
    .dialog-closeClose button (top-right)
    .sr-onlyScreen reader only text

    JavaScript API Reference

    Data Attribute Description
    data-dialogRequired on container element
    data-dialog-trigger="id"Trigger button (value = dialog id)
    data-dialog-closeCloses dialog on click
    data-close-on-overlay="false"Disable overlay click to close
    data-close-on-escape="false"Disable ESC key to close
    Method Description
    dialog.open()Opens the dialog
    dialog.close()Closes the dialog
    dialog.toggle()Toggles open/close state
    dialog.destroy()Destroys instance and cleans up
    Event Description
    dialog:openFired when dialog opens
    dialog:closeFired when dialog closes
