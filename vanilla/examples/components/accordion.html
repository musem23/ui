    Accordion

    A vertically stacked set of interactive headings that reveal or hide associated content.

    Installation

    <link rel="stylesheet" href="css/components/accordion.css"> <script src="js/core.js"></script> <script src="js/components/accordion.js"></script>

    Default

    Single mode accordion where only one item can be open at a time. Clicking an open item collapses it.

    // Programmatic control
const accordion = document.getElementById('accordion-multiple');

// Open all items
BrandUI.accordion.get(accordion)?.openAll();

// Close all items
BrandUI.accordion.get(accordion)?.closeAll();

// Open specific item
BrandUI.accordion.open(accordion, 'section-1');

// Close specific item
BrandUI.accordion.close(accordion, 'section-1');

    Keyboard Navigation

    Key Action
    Enter / SpaceToggle the focused accordion item
    Arrow DownMove focus to the next trigger
    Arrow UpMove focus to the previous trigger
    HomeMove focus to the first trigger
    EndMove focus to the last trigger

    Data Attributes Reference

    Attribute Description
    data-accordionInitialize accordion on this element (required)
    data-accordion-type"single" (default) or "multiple"
    data-accordion-collapsible"true" (default) or "false" - Allow closing all items in single mode
    data-accordion-default-valueValue of initially open item(s). String for single, JSON array for multiple.
    data-valueUnique identifier for each accordion item (on .accordion-item)

    CSS Classes Reference

    Class Description
    .accordionContainer element
    .accordion-itemIndividual accordion item wrapper
    .accordion-triggerClickable header button
    .accordion-trigger-iconChevron icon (rotates when open)
    .accordion-contentCollapsible content wrapper
    .accordion-content-innerInner wrapper for content padding

    Events

    Event Description
    accordion:openFired when an item opens. e.detail.value contains the item value.
    accordion:closeFired when an item closes. e.detail.value contains the item value.
     
    // Listen for accordion events
document.addEventListener('accordion:open', (e) => {
  console.log('Opened:', e.detail.value);
});

document.addEventListener('accordion:close', (e) => {
  console.log('Closed:', e.detail.value);
});
