    Sidebar

    A responsive collapsible sidebar with mobile sheet support. Supports offcanvas collapse, icon mode, and multiple variants.

    Installation

    <link rel="stylesheet" href="css/components/sidebar.css"> <script src="js/core.js"></script> <script src="js/components/sidebar.js"></script>

    Overview

    The Sidebar component provides a responsive navigation panel that collapses to slide off-screen (offcanvas) by default. On mobile devices, it becomes a sheet overlay. Use keyboard shortcut Cmd/Ctrl + B to toggle.

    Collapsible Modes

    The sidebar supports three collapse modes via the data-collapsible attribute:

    • offcanvas - Slides completely off-screen (default)
    • icon - Collapses to show only icons
    • none - Non-collapsible, always visible

    Variants

    Use the data-variant attribute to change the sidebar style:

    • sidebar - Default style with border
    • floating - Rounded corners with shadow
    • inset - Inset style with background

    HTML Structure

    <!-- Sidebar Wrapper -->
<div class="sidebar-wrapper" data-sidebar data-variant="sidebar">
  <!-- Desktop Sidebar -->
  <aside class="sidebar" data-side="left" data-collapsible="offcanvas" data-state="expanded">
    <div class="sidebar-gap"></div>
    <div class="sidebar-container">
      <div class="sidebar-inner">
        <div class="app-sidebar-header">...</div>
        <div class="app-sidebar-content">
          <div class="sidebar-group">
            <div class="app-sidebar-group-label">Section</div>
            <div class="sidebar-group-content">
              <ul class="sidebar-menu">
                <li class="sidebar-menu-item">
                  <a href="#" class="sidebar-menu-button">
                    <svg>...</svg>
                    <span>Menu Item</span>
                  </a>
                </li>
              </ul>
            </div>
          </div>
        </div>
        <div class="sidebar-footer">...</div>
      </div>
      <button class="sidebar-rail"></button>
    </div>
  </aside>

  <!-- Mobile Overlay -->
  <div class="sidebar-overlay" data-open="false"></div>

  <!-- Mobile Sheet -->
  <div class="sidebar-mobile" data-side="left" data-open="false">
    <div class="sidebar-mobile-inner">...</div>
  </div>

  <!-- Main Content -->
  <div class="sidebar-inset">
    <button class="sidebar-trigger" data-sidebar-trigger>Toggle</button>
    ...
  </div>
</div>

    JavaScript API

    // Get sidebar instance
const wrapper = document.querySelector('.sidebar-wrapper');
const sidebar = BrandUI.getInstance(wrapper, 'sidebar');

// Toggle sidebar
sidebar.toggle();

// Open/close programmatically
sidebar.open();
sidebar.close();

// Mobile specific
sidebar.openMobile();
sidebar.closeMobile();

// Set open state
sidebar.setOpen(true);
sidebar.setOpen(false);

// Get current state
const state = sidebar.getState();
// { state: 'expanded'|'collapsed', open: boolean, openMobile: boolean, isMobile: boolean }

// Properties
sidebar.isOpen;       // boolean
sidebar.isMobileOpen; // boolean
sidebar.isMobile;     // boolean
sidebar.state;        // 'expanded' | 'collapsed'

// Listen for events
wrapper.addEventListener('sidebar:open', (e) => {
  console.log('Sidebar opened');
});

wrapper.addEventListener('sidebar:close', (e) => {
  console.log('Sidebar collapsed');
});

wrapper.addEventListener('sidebar:open-mobile', (e) => {
  console.log('Mobile sidebar opened');
});

wrapper.addEventListener('sidebar:close-mobile', (e) => {
  console.log('Mobile sidebar closed');
});

wrapper.addEventListener('sidebar:change', (e) => {
  console.log('State changed:', e.detail);
});

// Destroy instance
sidebar.destroy();

    Menu Components

    Available menu-related classes:

    • .sidebar-menu - Menu container (ul)
    • .sidebar-menu-item - Menu item wrapper (li)
    • .sidebar-menu-button - Clickable menu button/link
    • .sidebar-menu-badge - Badge for notifications/counts
    • .sidebar-menu-action - Action button (e.g., more options)
    • .sidebar-menu-sub - Submenu container
    • .sidebar-menu-sub-item - Submenu item
    • .sidebar-menu-sub-button - Submenu button/link
    • .sidebar-menu-skeleton - Loading skeleton

    Button Sizes

    Use data-size attribute on menu buttons:

    <!-- Small -->
<a class="sidebar-menu-button" data-size="sm">Small</a>

<!-- Default -->
<a class="sidebar-menu-button">Default</a>
<a class="sidebar-menu-button" data-size="default">Default</a>

<!-- Large -->
<a class="sidebar-menu-button" data-size="lg">Large</a>

    Active State

    Mark a menu item as active with data-active="true":

    <a class="sidebar-menu-button" data-active="true">
  <svg>...</svg>
  <span>Active Item</span>
</a>

    Tooltips (Icon Mode)

    When using data-collapsible="icon", add tooltips with the data-tooltip attribute:

    <a class="sidebar-menu-button" data-tooltip="Dashboard">
  <svg>...</svg>
  <span>Dashboard</span>
</a>

    Keyboard Shortcuts

    The sidebar supports keyboard navigation:

    • Cmd/Ctrl + B - Toggle sidebar
    • Escape - Close mobile sidebar

    CSS Variables

    :root {
  --sidebar-width: 16rem;        /* Desktop width */
