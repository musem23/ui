    Dropdown Menu

    Displays a menu to the user with support for keyboard navigation, submenus, checkable items, and radio groups.

    Installation

    <link rel="stylesheet" href="css/components/dropdown-menu.css"> <script src="js/core.js"></script> <script src="js/components/dropdown-menu.js"></script>

    Basic Dropdown

    <div class="dropdown-menu" data-dropdown-menu>
  <button class="dropdown-menu-trigger btn btn-outline">

    <svg ...>...</svg>
  </button>
  <div class="dropdown-menu-content">
    <button class="dropdown-menu-item">New File</button>
    <button class="dropdown-menu-item">Open</button>
    <button class="dropdown-menu-item">Save</button>

    Data Attributes Reference

    Attribute Description
    data-dropdown-menuInitializes the dropdown menu component
    data-close-on-select="false"Keeps menu open after item selection
    data-close-on-click-outside="false"Prevents closing when clicking outside
    data-loop="false"Disables keyboard navigation looping
    data-align="end"Aligns menu to the end of the trigger
    data-side="top"Opens menu above the trigger
    data-disabledDisables a menu item
    data-variant="destructive"Applies destructive styling to item
    data-insetAdds left padding for icon alignment

    CSS Classes Reference

    Class Description
    .dropdown-menuContainer for the dropdown
    .dropdown-menu-triggerButton that opens the menu
    .dropdown-menu-contentThe dropdown panel container
    .dropdown-menu-itemStandard menu item
    .dropdown-menu-labelNon-interactive label/heading
    .dropdown-menu-separatorHorizontal divider line
    .dropdown-menu-shortcutKeyboard shortcut text
    .dropdown-menu-checkbox-itemToggleable checkbox item
    .dropdown-menu-radio-itemRadio selection item
    .dropdown-menu-radio-groupGroups radio items together
    .dropdown-menu-subSubmenu container
    .dropdown-menu-sub-triggerSubmenu trigger item
    .dropdown-menu-sub-contentSubmenu panel

    JavaScript Events

    Event Description
    dropdown-menu:openFired when the menu opens
    dropdown-menu:closeFired when the menu closes
    dropdown-menu:selectFired when an item is selected
    dropdown-menu:changeFired when checkbox/radio state changes
