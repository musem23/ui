    Resizable

    A component that allows resizing panels by dragging handles between them.

    Horizontal Layout

    Drag the handle between panels to resize. Panels are distributed evenly by default.

    Panel 1

    Panel 2

    67%

    <!-- Panel 1 content -->
  </div>
  <div class="resizable-handle">
    <div class="resizable-handle-grip"></div>
  </div>
  <div class="resizable-panel" data-default-size="67">
    <!-- Panel 2 content -->
  </div>
</div>

    Programmatic Control

    Control panel sizes via JavaScript API.

    Panel 1

    50%

    Panel 2

    50% 
    // Get resizable instance
const resizable = BrandUI.getInstance(element, 'resizable');

// Get current sizes
const sizes = resizable.getSizes();
// Returns: [{ percent: 50, pixels: 400 }, { percent: 50, pixels: 400 }]

// Set sizes programmatically (percentages)
resizable.setSizes([25, 75]);

// Listen for resize events
element.addEventListener('resizable:resize', (e) => {
  console.log('Sizes:', e.detail.sizes);
});

element.addEventListener('resizable:resizeend', (e) => {
  console.log('Resize complete:', e.detail.sizes);
});

    Keyboard Navigation

    The resizable handles support full keyboard navigation:

    • Arrow Left/Right - Resize horizontal panels (10px step)
    • Arrow Up/Down - Resize vertical panels (10px step)
    • Shift + Arrow - Larger resize step (50px)
    • Home - Collapse panel to minimum
    • End - Expand panel to maximum
    • Enter/Space - Toggle panel collapse
