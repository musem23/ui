    Popover

    Positioned floating content that appears on click. Supports multiple positions and alignments.

    Installation

    <link rel="stylesheet" href="css/components/popover.css"> <script src="js/core.js"></script> <script src="js/components/popover.js"></script>

    Basic Popover

    Popover Title

    This is the popover content. Click outside or press ESC to close.

    <div class="popover" data-popover>
  <button class="btn btn-outline popover-trigger" data-popover-trigger>
    Open Popover
  </button>
  <div class="popover-content" data-popover-content>
    <h4>Popover Title</h4>
    <p>This is the popover content.</p>
  </div>
</div>
    /* Required CSS */
@import "css/tokens.css";
@import "css/components/popover.css";

/* Core styles */
.popover { position: relative; display: inline-block; }
.popover-content {
  position: absolute;
  z-index: var(--z-popover);
  width: 18rem;
  padding: 1rem;
  background: var(--popover);
  border: 1px solid var(--border);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-md);
}
    // Auto-initialized via data-popover attribute
// Or manually initialize:
const element = document.querySelector('[data-popover]');
const popover = BrandUI.createPopover(element);

// API methods
popover.open();
popover.close();
popover.toggle();
popover.isOpen(); // returns boolean
popover.destroy();

    Data Attributes Reference

    Attribute Element Description
    data-popoverContainerRoot popover element (required for auto-init)
    data-popover-triggerTriggerElement that opens the popover on click
    data-popover-contentContentThe popover content container
    data-sideContentPosition: top, right, bottom (default), left
    data-alignContentAlignment: start, center (default), end
    data-stateContentState: open, closed (set automatically by JS)

    CSS Classes Reference

    Class Description
    .popoverContainer element (position: relative)
    .popover-triggerTrigger button styling
    .popover-contentContent panel with positioning and animation
    .popover-arrowOptional arrow pointing to trigger
    .popover-smSmall size (12rem width)
    .popover-lgLarge size (24rem width)
    .popover-autoAuto width (fits content)
    .no-animationDisable open/close animation

    JavaScript Events

    Event Description
    popover:openFired when popover opens
    popover:closeFired when popover closes
    popover:destroyFired when popover instance is destroyed
