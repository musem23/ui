    Avatar

    An image element with a fallback for representing the user.

    Installation

    <link rel="stylesheet" href="css/components/avatar.css">

    With Image

    <div class="avatar">
  <img class="avatar-image" src="..." alt="User avatar">
</div>
    /* Required CSS */
@import "css/tokens.css";
@import "css/components/avatar.css";

    CSS Classes Reference

    Class Description
    .avatarBase avatar container (required)
    .avatar-imageAvatar image element
    .avatar-fallbackFallback element for initials
    .avatar-xsExtra small size (1.5rem)
    .avatar-smSmall size (2rem, default)
    .avatar-mdMedium size (2.5rem)
    .avatar-lgLarge size (3rem)
    .avatar-xlExtra large size (4rem)
    .avatar-2xl2x extra large size (5rem)
    .avatar-groupContainer for stacked avatars
    .avatar-statusBase status indicator
    .avatar-status-onlineGreen online status
    .avatar-status-offlineGray offline status
    .avatar-status-busyRed busy status
