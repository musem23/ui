    Tabs

    A set of layered sections of content, displayed one at a time.

    Installation

    <link rel="stylesheet" href="css/components/tabs.css"> <script src="js/core.js"></script> <script src="js/components/tabs.js"></script>

    // Listen for tab changes
document.getElementById('my-tabs').addEventListener('tabs:change', (e) => {
  console.log('Tab changed:', e.detail);
  // e.detail contains: { index, value, trigger, panel }
});

// Programmatic API
BrandUI.ready(() => {
  const tabs = BrandUI.getInstance(document.getElementById('my-tabs'), 'tabs');

  // Select by index
  tabs.select(1);

  // Select by value
  tabs.selectByValue('second');

  // Get active state
  console.log('Active index:', tabs.getActiveIndex());
  console.log('Active value:', tabs.getActiveValue());
});

    Keyboard Navigation

    Tabs support full keyboard navigation for accessibility:

    • Arrow Left / Arrow Right - Navigate between tabs
    • Home - Go to first tab
    • End - Go to last tab
    • Enter / Space - Activate focused tab

    Data Attributes Reference

    Attribute Element Description
    data-tabs Container Initializes the tabs component (required)
    data-default-value Container Sets the initially active tab by value
    data-value Trigger / Content Links triggers to their content panels
    disabled Trigger Disables a tab trigger

    CSS Classes Reference

    Class Description
    .tabs Container element (required)
    .tabs-list Wrapper for tab triggers
    .tabs-trigger Tab button element
    .tabs-content Tab panel content

    JavaScript API Reference

    Method Description
    select(index) Activate a tab by its index (0-based)
    selectByValue(value) Activate a tab by its data-value
    getActiveIndex() Returns the current active tab index
    getActiveValue() Returns the current active tab value
    destroy() Removes the component instance
