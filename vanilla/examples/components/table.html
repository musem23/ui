    Table

    A responsive table component for displaying tabular data with rows and columns.

    Installation

    <link rel="stylesheet" href="css/components/table.css">

    Basic Table

    Invoice Status Method Amount
    INV001 Paid Credit Card $250.00
    INV002 Pending PayPal $150.00
    INV003 Unpaid Bank Transfer $350.00 
    <div class="table-container">
  <table class="table">
    <thead class="table-header">
      <tr class="table-row">
        <th class="table-head">Invoice</th>
        <th class="table-head">Status</th>
        <th class="table-head">Method</th>
        <th class="table-head table-head-right">Amount</th>
      </tr>
    </thead>
    <tbody class="table-body">
      <tr class="table-row">
        <td class="table-cell">INV001</td>
        <td class="table-cell">Paid</td>
        <td class="table-cell">Credit Card</td>
        <td class="table-cell table-cell-right">$250.00</td>
      </tr>
      ...
    </tbody>
  </table>
</div>

    CSS Classes Reference

    Class Description
    .table-container Wrapper for horizontal scroll on overflow
    .table Base table class (required)
    .table-header Table header (thead) styling
    .table-body Table body (tbody) styling
    .table-footer Table footer (tfoot) styling
    .table-row Table row (tr) styling
    .table-head Table header cell (th) styling
    .table-cell Table data cell (td) styling
    .table-caption Table caption styling
    .table-striped Alternating row background colors
    .table-bordered Adds borders to all cells
    .table-compact Reduced padding for dense data
    .table-head-right Right-align header cell content
    .table-head-center Center-align header cell content
    .table-cell-right Right-align data cell content
    .table-cell-center Center-align data cell content
