    Tooltip

    Display helpful text when users hover over or focus on an element.

    Installation

    <link rel="stylesheet" href="css/components/tooltip.css"> <script src="js/core.js"></script> <script src="js/components/tooltip.js"></script>

    Basic Tooltip

    This is a tooltip
    <div class="tooltip" data-tooltip>
  <button class="tooltip-trigger">Hover me</button>
  <div class="tooltip-content">This is a tooltip</div>
</div>

    JavaScript API

    Controlled via JS
    // Get tooltip instance
const element = document.querySelector('#my-tooltip');
const tooltip = BrandUI.getInstance(element, 'tooltip');

// Methods
tooltip.show();           // Show the tooltip
tooltip.hide();           // Hide the tooltip
tooltip.toggle();         // Toggle visibility
tooltip.setPosition('bottom');  // Change position
tooltip.destroy();        // Destroy instance

    Data Attributes Reference

    Attribute Description Default
    data-tooltipInitializes the tooltip component (required)-
    data-tooltip-positionPosition of tooltip: top, right, bottom, lefttop
    data-tooltip-delayShow delay in milliseconds200
