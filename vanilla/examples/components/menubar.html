    Keyboard Navigation

    Full keyboard support for accessible navigation.

    Key Action
    Arrow Left/Right Navigate between menus
    Arrow Up/Down Navigate within menu
    Enter / Space Open menu or select item
    Escape Close current menu/submenu
    Home / End Jump to first/last item
    Arrow Right on submenu Open submenu
