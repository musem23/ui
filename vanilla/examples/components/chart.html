    Chart

    SVG-based chart components for data visualization including bar, line, and pie charts.

    Bar Chart

    Displays data with rectangular bars proportional to the values they represent.

    Monthly Revenue
    Revenue data for the first half of 2024

    Line Chart

    Displays data points connected by straight line segments.

    User Growth
    Active users over the past 6 months

    Area Chart

    Line chart with filled area under the line.

    Page Views
    Daily page views this week

    Pie Chart

    Displays data as proportional segments of a circle.

    Traffic Sources
    Distribution of website traffic by source

    Multi-Series Bar Chart

    Compares multiple data series side by side.

    Sales Comparison
    This year vs last year sales data

    Usage

    How to create charts with the Chart component.

    // Create a bar chart
const barChart = BrandUI.createChart(document.getElementById('my-chart'), {
  type: 'bar',
  data: [
    { label: 'Jan', value: 31250 },
    { label: 'Feb', value: 37500 },
    { label: 'Mar', value: 27500 },
  ],
  seriesName: 'Revenue'
});

// Create a line chart
const lineChart = BrandUI.createChart(element, {
  type: 'line', // or 'area' for filled area
  data: [
    { label: 'Jan', value: 325 },
    { label: 'Feb', value: 450 },
    { label: 'Mar', value: 575 },
  ]
});

// Create a pie chart
const pieChart = BrandUI.createChart(element, {
  type: 'pie',
  data: [
    { label: 'Direct', value: 35 },
    { label: 'Organic', value: 30 },
    { label: 'Referral', value: 20 },
  ]
});

// Multi-series bar chart
const multiBarChart = BrandUI.createChart(element, {
  type: 'bar',
  data: [
    { label: 'Q1', values: { 'Last Year': 42, 'This Year': 52 } },
    { label: 'Q2', values: { 'Last Year': 48, 'This Year': 60 } },
  ]
});

// Update chart data
barChart.setData(newData);

// Change chart type
barChart.setType('line');

// Update options
barChart.update({ showGrid: false });
