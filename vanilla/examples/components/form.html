    Form with Validation

    Interactive form demonstrating JavaScript validation.

    We'll use this to contact you.

    At least 8 characters required.

    // Initialize form validation
const form = document.getElementById('validation-form');
const formApi = BrandUI.components.Form.initForm(form);

// Set custom validators
formApi.setValidators({
  email: (value) => {
    if (!value.includes('@company.com')) {
      return 'Please use your company email';
    }
  }
});

    Programmatic API

    Control form items programmatically via JavaScript.

    Use the buttons below to change the state.

    const item = BrandUI.components.Form.initItem(element);

// Set states
item.setError('This field has an error');
item.setSuccess('Looks good!');
item.setWarning('Please double-check this');
item.clearError();

// Toggle properties
item.setDisabled(true);
item.setRequired(true);

// Get current state
const state = item.getState();
// { hasError, isDisabled, value, inputElement }
