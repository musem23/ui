    Progress

    A progress bar that indicates the completion status of a task or process.

    Basic Progress

    A simple progress bar showing completion percentage.

    33%
    66%
    100% 
    <div
  class="progress"
  role="progressbar"
  aria-valuenow="33"
  aria-valuemin="0"
  aria-valuemax="100"
>
  <div class="progress-indicator" style="transform: translateX(-67%);"></div>
</div>

    Animated Progress

    Progress bar with smooth animation when value changes.

    0% 
    // Update progress programmatically
function setProgress(value) {
  const progress = document.getElementById('animated-progress');
  const indicator = progress.querySelector('.progress-indicator');

  progress.setAttribute('aria-valuenow', value);
  indicator.style.transform = `translateX(-${100 - value}%)`;
}

    Accessibility

    The progress component includes proper ARIA attributes for screen readers:

    • role="progressbar" - Identifies the element as a progress bar
    • aria-valuenow - Current progress value
    • aria-valuemin - Minimum value (typically 0)
    • aria-valuemax - Maximum value (typically 100)
    • aria-label - Optional descriptive label
