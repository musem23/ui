    Separator

    A visual divider that separates content sections horizontally or vertically.

    Installation

    <link rel="stylesheet" href="css/components/separator.css">

    Horizontal Separator

    Radix Primitives

    An open-source UI component library.

    Brand UI

    A CSS-only component library.

    <div class="separator separator-horizontal" role="separator" aria-orientation="horizontal"></div>
    /* Required CSS */
@import "css/tokens.css";
@import "css/components/separator.css";

/* Separator CSS */
.separator {
  flex-shrink: 0;
  background-color: var(--border);
}

.separator-horizontal {
  height: 1px;
  width: 100%;
}

    CSS Classes Reference

    Class Description
    .separatorBase separator class (required)
    .separator-horizontalHorizontal divider (full width, 1px height)
    .separator-verticalVertical divider (full height, 1px width)

    Accessibility

    Attribute Description
    role="separator"Indicates a semantic separator for assistive technologies
    aria-orientationSet to "horizontal" or "vertical" to match visual orientation
    role="none"Use for purely decorative separators with no semantic meaning
