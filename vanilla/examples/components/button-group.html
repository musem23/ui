    Button Group

    Button Group

    Group a series of buttons together on a single line or vertically.

    Installation

    <link rel="stylesheet" href="css/components/button-group.css"> <link rel="stylesheet" href="css/components/button.css">

    Horizontal (Default)

    <div class="btn-group" role="group">
  <button class="btn btn-outline">Left</button>
  <button class="btn btn-outline">Middle</button>
  <button class="btn btn-outline">Right</button>
</div>

    Vertical

    <div class="btn-group btn-group-vertical" role="group">
  <button class="btn btn-outline">Top</button>
  <button class="btn btn-outline">Middle</button>
  <button class="btn btn-outline">Bottom</button>
</div>

    With Icons

    <div class="btn-group" role="group">
  <button class="btn btn-outline btn-icon" aria-label="Bold">
    <svg>...</svg>
  </button>
  <button class="btn btn-outline btn-icon" aria-label="Italic">
    <svg>...</svg>
  </button>
  <button class="btn btn-outline btn-icon" aria-label="Underline">
    <svg>...</svg>
  </button>
</div>

    Mixed Button Variants

    <div class="btn-group" role="group">
  <button class="btn btn-default">Save</button>
  <button class="btn btn-outline btn-icon" aria-label="More options">
    <svg>...</svg>
  </button>
</div>

    With Text Addon

    Sort by: 
    <div class="btn-group" role="group">
  <span class="btn-group-text">Sort by:</span>
  <button class="btn btn-outline">Name</button>
  <button class="btn btn-outline">Date</button>
  <button class="btn btn-outline">Size</button>
</div>

    Sizes

    <!-- Small -->
<div class="btn-group" role="group">
  <button class="btn btn-outline btn-sm">Small</button>
  <button class="btn btn-outline btn-sm">Group</button>
</div>

<!-- Default -->
<div class="btn-group" role="group">
  <button class="btn btn-outline">Default</button>

<!-- Large -->
<div class="btn-group" role="group">
  <button class="btn btn-outline btn-lg">Large</button>

    With Separator

    <div class="btn-group" role="group">
  <button class="btn btn-outline">Cut</button>
  <div class="btn-group-separator btn-group-separator-vertical"></div>
  <button class="btn btn-outline">Copy</button>
  <div class="btn-group-separator btn-group-separator-vertical"></div>
  <button class="btn btn-outline">Paste</button>
</div>

    CSS Classes Reference

    Class Description
    .btn-groupBase button group container
    .btn-group-verticalVertical button group layout
    .btn-group-textText addon element
    .btn-group-separatorSeparator between buttons
    .btn-group-separator-verticalVertical separator line
