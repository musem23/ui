    Toggle Group

    Toggle Group

    A set of two-state buttons that can be toggled on or off. Supports single and multiple selection modes.

    Single Selection

    Only one item can be selected at a time. Clicking a selected item deselects it.

    <div class="toggle-group" role="group" aria-label="Text alignment" data-toggle-group data-type="single" data-spacing="0">
  <button type="button" class="toggle-group-item" aria-pressed="true" data-value="left">
    <!-- Left align icon -->
  </button>
  <button type="button" class="toggle-group-item" aria-pressed="false" data-value="center">
    <!-- Center align icon -->
  </button>
  <button type="button" class="toggle-group-item" aria-pressed="false" data-value="right">
    <!-- Right align icon -->
  </button>
</div>

    Multiple items can be selected simultaneously.

    Disabled

    Programmatic Control

    Control toggle group state via JavaScript API.

    Selected: none
    // Get toggle group instance
const group = BrandUI.getInstance(element, 'toggle-group');

// Get selected value (single mode)
group.getValue();

// Get selected values (multiple mode)
group.getValues();

// Set value
group.setValue('option1');

// Clear all selections
group.clear();

// Listen for changes
element.addEventListener('toggle-group:change', (e) => {
  console.log('Selected:', e.detail.value);
});

    With Text Labels

    Toggle group items can contain text labels with or without icons.
